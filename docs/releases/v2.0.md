FLYWHEEL v2.0 is a machine-checked matrix analysis library for Lean 4 and Mathlib. It builds on Lean `v4.35.0` with Mathlib pinned at [`ccbef15`](https://github.com/leanprover-community/mathlib4/tree/ccbef15ebdb41c2addfac682131f83c75904c3c1).

## Sorry-free and axiom-free

This is the first release with no `sorry`, `admit` or `axiom`. CI checks that every declaration in the 12 libraries depends only on `propext`, `Classical.choice` and `Quot.sound`.

Release 1.0 was not in that state. It had:
- an axiom, `exists_spectral_minimizer_rank1`. It is now a theorem, `Matrix.Coherence.exists_spectral_minimizer_rank1`, witnessed by the rank-1 truncated SVD.
- a `sorry` in `SVD.lean`, in a lemma that is not provable as stated. It equated two independent `Trunc.out` choices. The SVD now uses Mathlib's own eigenvalue bijection, so the lemma is no longer needed.
- a `sorry` in `TightBounds.lean`, in `frobenius_spectral_coincide_high_coherence`. That statement is false, so it was removed, and the source now gives an explicit counterexample.
- a rectangular SVD statement, `svd_decomposition_rectangular`, that was vacuous: `U = V = 1`, `S = A` proved it. It now states `A = U * rectDiagonal σ * star V` with `σ ≥ 0` antitone.

## New results

- **Rectangular Eckart–Young:** `Matrix.TightBounds.eckart_young_frobenius_rect` and `eckart_young_spectral_rect`.
  - They come with rectangular Thompson interlacing (`Matrix.WeylInequality.thompson_interlacing_rect`).
  - The truncation error formulas and the rank bound (`truncatedSVD_rect_rank_le`) are also proved.
- **Van Loan–Pitsianis:** `Matrix.TightBounds.kroneckerApprox_optimal`. The Kronecker approximation from the rank-1 SVD of `R(C)` is Frobenius-optimal.
- **Courant–Fischer:** the max-min and min-max equalities (`courantFischer_maxMin`, `courantFischer_minMax`), not just the bounds.
- **Uniqueness under a gap (Frobenius)**, in the new library `FrobeniusUniqueness`:
  - `eckart_young_frobenius_unique` (square);
  - `eckart_young_frobenius_rect_unique` (m × n);
  - `kroneckerApprox_unique` (unique as the product `A ⊗ B`, not as the pair of factors).
- **Spectral non-uniqueness:** `Matrix.SVD.spectral_best_rank_one_not_unique`. For `A = diag(2, 1)`, both `diag(2, 0)` and `diag(3/2, 0)` are best rank-1 approximations.
- **Davis–Kahan**, in the new library `DavisKahan`:
  - the sin θ bound for the top eigenvector (`davis_kahan_top_eigenvector`);
  - the Frobenius sin Θ bound for the top-k eigenspace, with a factor k (`davis_kahan_sin_theta`);
  - a perturbation bound for the top right singular vector of a square matrix, via `AᴴA` (`top_right_singular_vector_perturbation`).
- **Spectral vs. Frobenius norm:**
  - `‖E‖₂ = ‖E‖_F` holds iff `rank E ≤ 1`, for rectangular `E` (`spectral_eq_frobenius_rect_iff_rank_le_one`);
  - the same for `R⁻¹X` (`R_inv_spectral_eq_frobenius_iff_rank_le_one`);
  - stable rank ≤ effective rank (`stableRank_le_effectiveRank`).

## Breaking changes

- **Layout:** the Lake project moved from `src/` to the repo root. `lakefile.toml`, `lean-toolchain` and `lake-manifest.json` are at the root, and sources stay in `src/`.
- **Toolchain:** Lean `v4.26.0-rc2` → `v4.35.0`.
- **Mathlib:** it was unpinned (`master`) and is now pinned by commit.
- **Module system:** every file is a Lean module (`module`, `public import`, `@[expose] public section`).
- **Renamed namespaces:**
  - `Matrix.Kronecker.SpectralGap` and `Matrix.Kronecker.SpectralGapCharacterization` merged into `Matrix.Kronecker.SpectralBounds`;
  - the square spectral Eckart–Young moved to `Matrix.SVD`.
- **Removed declarations:** duplicate, trivial and wrapper declarations, unused aliases, and unused hypotheses.
- **Changed statements:** a few theorem statements changed. Besides the rectangular SVD, they now spell `Set.domRestrict` for `Set.restrict` and drop unused hypotheses.

`docs/INDEX.md` lists every declaration with its full name, file and line.

## Tooling

- CI runs `lake build --wfail`, so any warning fails the build. It also runs a per-declaration axiom check (`scripts/CheckAxioms.lean`) and checks that the index is current.
- `docs/` contains proof-architecture notes: `svd.md`, `eckart-young.md`, `kronecker.md` and `davis-kahan.md`.
